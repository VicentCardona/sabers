Introducció a la Programació en C: De Scratch a la Consola

Apunts complets de la Setmana 1 del curs CS50 d'Harvard. Transició visual a textual, entorn en el núvol (cs50.dev), cicle de compilació, gestió d'entrades amb la llibreria cs50.h, control de flux i bones pràctiques d'enginyeria.

Informàtica Bàsica Llenguatge C CS50x / GNU Linux
PART I · FLUX DE TREBALL I PRIMERS PASSOS

1. L'Entorn cs50.dev i l'Ordinador per Terminal

A diferència dels programes de disseny visual com Scratch, en C treballem directament amb la consola (CLI o Command Line Interface). Per estalviar configuracions locals de compiladors, emprem cs50.dev, una màquina virtual basada en VS Code allotjada al núvol.

📁 Ordres Bàsiques de Linux

La consola no utilitza ratolí: ens movem per carpetes i arxius mitjançant text:

  • ls: llista tots els fitxers i carpetes del directori actual.
  • cd nom_carpeta: canvia el directori de treball cap endavant.
  • cd ..: retrocedeix un nivell en l'arbre de directoris.
  • mkdir nom: crea una nova carpeta (make directory).
  • rm nom_fitxer: esborra de manera permanent un fitxer.
  • cp i mv: copia i mou (o reanomena) fitxers.

☁️ Per què cs50.dev?

Un dels problemes històrics d'ensenyar llenguatges de baix nivell com C és la instal·lació dels compiladors (GCC o Clang) i les dependències segons cada sistema operatiu (Windows, macOS o Linux).

Amb cs50.dev, cada alumne disposa d'un entorn idèntic configurat amb les eines make, clang, check50 i style50.

2. Codi Font, Compilador i Codi Màquina

Els ordinadors només comprenen senyals binaris: patrons de 0s i 1s (codi màquina). Els humans, en canvi, escrivim en instruccions llegibles conegudes com a codi font (arxius acabats en .c).

El procés de Compilació: És el programa traductor (compilador) que transforma les nostres sentències de C en zeros i uns executables pel microprocessador:

Codi Font (.c)  →  COMPILADOR (Clang / Make)  →  Executable (Binari)
# 1. Obrir l'arxiu i escriure el codi
code hello.c

# 2. Compilar (NO posar l'extensió .c amb make!)
make hello

# 3. Executar el fitxer generat en el directori actual
./hello

3. El Primer Programa: "hello, world"

Anatomia bàsica d'un programa en C. Cada símbol, clau i punt i coma compleix una funció estrictament necessària.

// Programa inicial tradicional en C
#include int main(void){printf("hello, world\n");}        

            

                
Anatomia del Codi

                
    
                    
  • #include <stdio.h>: fitxer de capçalera (header file) que conté funcions d'entrada/eixida estàndard com printf.
    • 
                    
  • int main(void): el punt d'inici obligatori de qualsevol programa en C.
    • 
                    
  • \n: seqüència d'escapament que representa un salt de línia.
    • 
                    
  • ;: cada sentència ha d'acabar amb punt i coma. Si l'ometem, el compilador llançarà un error de sintaxi.
    • 
                

            

            

                
Seqüències d'Escapament Comuns

                
    
                    
  • \n: Salt de línia.
    • 
                    
  • \t: Tabulació horitzontal.
    • 
                    
  • \": Permet imprimir unes cometes dobles sense tancar el string.
    • 
                    
  • \\: Imprimeix una barra invertida literal.

PART II · GESTIÓ DE DADES I ESTRUCTURES DE CONTROL

4. Tipus de Dades i Especificadors de Format

En Scratch les variables eren comodins que podien contindre nombres o text indistintament. En C, cal definir de manera explícita quant d'espai de memòria necessita cada variable.

Tipus Descripció Format printf Funció d'Entrada (cs50.h)
int Sencers de 32 bits (aprox. -2.000 milions a +2.000 milions) %i o %d get_int()
long Sencers llargs de 64 bits per a quantitats gegants %li get_long()
float Nombres decimals (coma flotant de precisió simple) %f get_float()
double Nombres decimals amb el doble de precisió (64 bits) %lf get_double()
char Un sol caràcter entre cometes simples (ex: 'a', 'Y') %c get_char()
string Cadena de text entre cometes dobles (proporcionat per cs50.h) %s get_string()

Exemple interactiu: hello.c amb entrada d'usuari

#include <cs50.h>
#include int main(void){// Demanem el nom a l'usuari i el guardem en una variable de tipus stringstring name = get_string("Com et dius? ");// Substituïm %s pel contingut de la variable name
printf("Hola, %s!\n", name);
}    
    

        
5. Presa de Decisions (Condicionals)

        
Permeten que el programa seguisca rutes diferents segons si una condició booleana avalua com a vertadera (true / 1) o falsa (false / 0).


        

            

                
Comparadors i Operadors Lògics

                
    
                    
  • ==: Igualtat (Molt important: un sol = és assignació!).
    • 
                    
  • !=: Diferent de.
    • 
                    
  • < i >: Menor i major que.
    • 
                    
  • <= i >=: Menor o igual i major o igual.
    • 
                    
  • &&: AND lògic (totes han de ser certs).
    • 
                    
  • ||: OR lògic (almenys una certa).
    • 
                    
  • !: NOT lògic (inverteix el resultat).
    • 
                

            

            

                
Exemple d'elecció: agree.c

                
#include <cs50.h>
#include int main(void){char c = get_char("Hi estàs d'acord? (s/n): ");if (c == 's' || c == 'S')
{
    printf("D'acord.\n");
}
else if (c == 'n' || c == 'N')
{
    printf("No d'acord.\n");
}
else
{
    printf("Opció invàlida.\n");
}
}    
    

        
6. Repetició de Tasques (Bucles)

        
Per evitar repetir codi manualment, emprem estructures iteratives:


        

            

                
Bucle while

                
Executa el bloc mentre la condició siga vertadera. Comprovem la condició abans d'entrar:

                
int i = 0;
while (i < 3){printf("meow\n");i++;}            

                
Bucle for

                
Ideal quan coneixem d'antemà quantes vegades s'ha de repetir el cicle:

                
for (int i = 0; i < 3; i++)
{printf("meow\n");}        

            
Bucle do-while: Validació d'Entrades

            
Aquest bucle executa el codi intern almenys una vegada i només al final comprova la condició. És l'estructura estàndard per forçar a l'usuari a introduir dades correctes (filtratge d'errors):

            
#include <cs50.h>
#include int main(void){int n;// Obliguem a repetir mentre l'usuari pose valors menors a 1do{n = get_int("Introdueix un nombre positiu: ");}while (n < 1);for (int i = 0; i < n; i++)
{
    printf("meow\n");
}
}
