UP2: El meu primer llenguatge - C

Apunts complets de la Unitat de Programació 2 (UP2) de Programació i Tractament de Dades 1. Entorn de desenvolupament al núvol (cs50.dev), cicle de compilació, tipus de dades en memòria, entrades i eixides amb stdio.h i cs50.h, operadors, condicionals i disseny modular amb funcions.

PART I · FLUX DE TREBALL I PRIMERS PASSOS

1. L'Entorn al Núvol (cs50.dev) i la Consola Linux

A diferència dels llenguatges visuals per blocs com Scratch, en C treballem directament amb codi textual i la línia d'ordres (CLI). Per evitar discrepàncies de configuració entre sistemes operatius, utilitzem cs50.dev, un entorn de treball basat en Visual Studio Code que s'executa en un contenidor Linux al núvol.

📁 Ordres Fonamentals de la Shell

  • ls: llista fitxers i carpetes del directori actual.
  • cd nom_carpeta: canvia el directori de treball cap endavant.
  • cd ..: retrocedeix un nivell en l'arbre de directoris.
  • mkdir nom: crea una nova carpeta (make directory).
  • rm nom_fitxer: esborra de manera permanent un fitxer.
  • cp i mv: copia i mou (o reanomena) fitxers.

☁️ Avantatges de l'Entorn Preconfigurat

Garanteix que tot l'alumnat dispose exactament de les mateixes ferramentes ja instal·lades: el compilador clang, l'automatització amb make, la llibreria docent cs50.h per facilitar la lectura de dades per teclat, i utilitats d'anàlisi com debug50 i style50.

2. Codi Font, Compilador i Codi Màquina

El maquinari només executa patrons binaris de 0s i 1s (codi màquina). El text que escrivim en arxius .c és codi font, comprensible per humans, que requereix un compilador per traduir-se:

Cicle de Compilació:
Codi Font (.c)  →  COMPILADOR (Clang / Make)  →  Binari Executable
# 1. Obrir l'arxiu i escriure el codi font
code hello.c

# 2. Compilar invocant make (sense l'extensió .c!)
make hello

# 3. Executar l'executable binari generat
./hello

3. El Primer Programa: "hello, world" i Eixida per Pantalla

Anatomia bàsica d'un programa en C i impressió de text per consola:

// Programa inicial tradicional en C
#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
}

Anatomia del Codi

  • #include <stdio.h>: fitxer de capçalera (header file) d'entrada/eixida estàndard que ens permet utilitzar funcions com printf.
  • int main(void): punt d'entrada principal del programa. La paraula clau void entre parèntesis indica que la funció no rep cap argument inicial.
  • \n: seqüència d'escapament que produeix un salt de línia.
  • ;: tanca cada instrucció; oblidar-lo genera un error sintàctic de compilació.

Seqüències d'Escapament Habituals

  • \n: Salt de línia.
  • \t: Tabulació horitzontal.
  • \": Cometes dobles literals dins d'un string.
  • \\: Barra invertida literal.
PART II · TIPUS DE DADES, ENTRADES/EIXIDES I OPERADORS

4. Tipus de Dades, Variables i Entrades/Eixides

A diferència d'altres llenguatges on les variables determinen el seu tipus de forma dinàmica, en C cal especificar explícitament el tipus de cada variable en declarar-la per indicar al compilador quants bytes de memòria ha de reservar i com interpretar-los.

Tipus Mida Rang i Característiques Format printf (Eixida) Funció cs50.h (Entrada)
int 4 bytes (32 bits) Sencers amb signe: de -231 a 231 - 1 (~ ±2.000 milions) %i o %d get_int()
unsigned int 4 bytes (32 bits) Qualificador que duplica el rang positiu eliminant els negatius: de 0 a 232 - 1 (~ 0 a 4.000 milions) %u —
char 1 byte (8 bits) Caràcter únic entre cometes simples (-128 a 127). Mapeig ASCII: 'A'=65, 'a'=97, '0'=48 %c get_char()
float 4 bytes (32 bits) Nombres reals en coma flotant (precisió simple de 32 bits) %f (ex: %.2f) get_float()
double 8 bytes (64 bits) Nombres reals amb doble precisió (per a càlculs científics o molts decimals) %lf get_double()
bool 1 byte Valors lògics: true o false (disponible incloent <cs50.h> o <stdbool.h>) %i —
string Variable Cadena de text entre cometes dobles (tipus proporcionat per <cs50.h>) %s get_string()
void — Tipus especial que indica absència de valor o de paràmetres. No es pot assignar a una variable. — —

Declaració vs Inicialització

Crear una variable requereix indicar el seu tipus i el seu nom. Si li assignem un valor en el mateix moment de crear-la, s'anomena inicialització:

// 1. Declaració i assignació en línies separades
int number;          // Declaració
number = 17;         // Assignació

// 2. Inicialització directa
int edat = 20;      // Inicialització
char lletra = 'A';   // Mapeig ASCII 65

// Declaració múltiple del mateix tipus:
int ample, alt;     // Vàlid en C

Bones Pràctiques amb Variables

  • No redeclarar: Un cop declarada una variable (ex: int x;), utilitza-la directament pel seu nom (x = 10;). Tornar a escriure int x = 10; en el mateix bloc donarà error de compilació.
  • Format de decimals en printf: Pots limitar els decimals mostrats escrivint %.2f per mostrar exactament 2 decimals.
  • Correspondència de marcadors: Cada marcador (%i, %f, %s...) dins de printf ha de coincidir en ordre i en tipus amb les variables passades després de la coma.

Exemple d'Entrada i Eixida amb cs50.h i stdio.h

#include <cs50.h>
#include <stdio.h>

int main(void)
{
    // Lectura de diferents tipus de dades per teclat
    string nom = get_string("Com et dius? ");
    int edat = get_int("Quants anys tens? ");
    float nota = get_float("Quina nota esperes treure? ");

    // Impressió combinant diversos marcadors de format
    printf("Hola, %s! Tens %i anys i esperes un %.2f en l'examen.\n", nom, edat, nota);
}

5. Operadors Aritmètics, Relacionals i Lògics

C disposa d'un conjunt d'operadors per transformar valors numèrics i avaluar condicions lògiques.

Aritmètica i l'Operador Mòdul (%)

A més de la suma (+), resta (-), multiplicació (*) i divisió (/), disposem del mòdul:

  • %: Retorna el residu d'una divisió entera. Ex: 13 % 4 dóna com a resultat 1 (ja que 13 = 4 × 3 + 1).
  • Divisió entera: En C, si divideixes dos enters (ex: 5 / 2), el resultat es trunca a enter (2). Per conservar els decimals cal convertir un dels operands a float: (float) 5 / 2.
// Operadors aritmètics abreujats
x += 5;   // Equivalent a: x = x + 5
x *= 2;   // Equivalent a: x = x * 2

// Increment i decrement unitari
x++;      // Incrementa x en 1 (x = x + 1)
x--;      // Decrementa x en 1 (x = x - 1)

Expressions Booleanes i Lògiques

En C, qualsevol valor diferent de zero s'interpreta com a vertader (true), mentre que zero és fals (false).

  • ==: Igualtat. Compte: = és assignació, mentre que == és comparació.
  • !=: Diferent de (desigualtat).
  • <, >, <=, >=: Menor, major, menor o igual, major o igual.
  • && (AND): Cert només si tots dos operands són certs.
  • || (OR): Cert si com a mínim un operand és cert.
  • ! (NOT): Inverteix el valor lògic (de fals a cert i viceversa).
PART III · CONTROL DE FLUX I MODULARITAT

6. Presa de Decisions (Condicionals)

Permeten que el programa seguisca rutes d'execució diferents segons si una condició booleana s'avalua com a certa o falsa.

#include <cs50.h>
#include <stdio.h>

int main(void)
{
    char c = get_char("Hi estàs d'acord? (s/n): ");

    // Comprovem si l'usuari ha introduït 's' o 'S'
    if (c == 's' || c == 'S')
    {
        printf("D'acord.\n");
    }
    else if (c == 'n' || c == 'N')
    {
        printf("No d'acord.\n");
    }
    else
    {
        printf("Opció invàlida.\n");
    }
}

7. Disseny Modular: Funcions en C

Una funció és un bloc de codi independent dissenyat per realitzar una tasca concreta. Les funcions ens permeten dividir un problema complex en parts més menudes, evitar repetir codi i fer que el programa principal (main) siga molt més fàcil de llegir i mantenir.

Estructura general d'una funció:
tipus_retorn nom_funcio(tipus_param1 nom1, tipus_param2 nom2)
  • Tipus de retorn: El tipus de dada del resultat que la funció retorna a qui l'ha cridada (int, float, char...) o void si no retorna cap valor.
  • Paràmetres d'entrada: Les variables que rep la funció entre parèntesis per poder treballar (o void si no necessita rebre cap dada).
Important: El Prototip de la Funció
El compilador de C llegeix el fitxer de dalt a baix. Si definim les nostres funcions a sota de main, hem d'escriure el seu prototip (la primera línia de la funció acabada en punt i coma ;) a dalt del tot, abans de int main(void), perquè el compilador sàpia que existeixen.

Nivell 1: Funcions sense entrades ni retorn — void funcio(void)

Són funcions que no reben cap dada d'entrada (void entre parèntesis) ni retornen cap resultat numèric o de text (void al principi). S'utilitzen habitualment per mostrar missatges fixos, capçaleres o menús per pantalla.

#include <stdio.h>

// 1. Prototip de la funció (avisa al compilador)
void mostrar_benvinguda(void);

int main(void)
{
    // 2. Crida a la funció des de main (sense paràmetres)
    mostrar_benvinguda();
    printf("Iniciant el programa principal...\n");
}

// 3. Definició de la funció
void mostrar_benvinguda(void)
{
    printf("====================================\n");
    printf("  PROGRAMACIÓ I TRACTAMENT DADES 1  \n");
    printf("====================================\n");
}

Nivell 2: Funcions amb paràmetres d'entrada i sense retorn — void funcio(int a, int b)

Aquestes funcions tampoc retornen cap valor a main (comencen per void), però reben dades per paràmetre entre els parèntesis per poder operar amb elles i mostrar el resultat directament des de dins de la funció.

#include <cs50.h>
#include <stdio.h>

// Prototip: rep dos enters, però no retorna res (void)
void imprimir_suma(int a, int b);

int main(void)
{
    int num1 = get_int("Introdueix el primer nombre: ");
    int num2 = get_int("Introdueix el segon nombre: ");

    // Passem els valors de num1 i num2 a la funció
    imprimir_suma(num1, num2);
}

// Definició: 'a' rep el valor de 'num1' i 'b' rep el valor de 'num2'
void imprimir_suma(int a, int b)
{
    int resultat = a + b;
    printf("La suma de %i i %i és: %i\n", a, b, resultat);
}

Nivell 3: Funcions amb entrades i valor de retorn — tipus funcio(paràmetres)

És el format més complet i versàtil. La funció rep dades d'entrada (d'un o diversos tipus), fa un càlcul i retorna el resultat mitjançant la paraula clau return. Al main podem guardar aquest valor retornat dins d'una variable per seguir treballant amb ell.

#include <cs50.h>
#include <stdio.h>

// Prototips amb diferents tipus de retorn i paràmetres
int calcular_area(int base, int altura);
float calcular_mitjana(float nota1, float nota2);

int main(void)
{
    // Exemple 1: Funció que retorna un int
    int b = get_int("Base del rectangle: ");
    int h = get_int("Altura del rectangle: ");
    
    int area = calcular_area(b, h);
    printf("L'àrea del rectangle és: %i\n\n", area);

    // Exemple 2: Funció que retorna un float
    float n1 = get_float("Nota del primer examen: ");
    float n2 = get_float("Nota del segon examen: ");
    
    float final = calcular_mitjana(n1, n2);
    printf("La nota mitjana és: %.2f\n", final);
}

// Rep dos int i retorna un int
int calcular_area(int base, int altura)
{
    int  resultat = base * altura;
    return resultat;
}

// Rep dos float i retorna un float
float calcular_mitjana(float nota1, float nota2)
{
    return (nota1 + nota2) / 2.0;
}

Resum dels 3 Tipus de Funcions

  • void f(void): No rep dades ni retorna res. Fa una acció tancada.
  • void f(int a, float b): Rep dades per treballar, però no retorna cap valor amb return.
  • int f(int a, int b): Rep dades, les processa i retorna un resultat del tipus indicat amb return.

Àmbit de les Variables (Scope)

Les variables creades dins d'una funció (inclosos els seus paràmetres) són variables locals: només existeixen dins d'aquella funció. Per comunicar dades entre main i una funció, cal passar-les com a paràmetres i recollir el resultat amb return.

8. Bones Pràctiques, Disseny i Preparació per a l'Avaluació (UP2)

En programació no només s'avalua que el programa compile i funcione (Correcció), sinó també l'ordre, l'estructura modular i la claredat del codi (Estil i Disseny):

🛠️ Eines de Suport en l'Entorn

  • style50 nom.c: Avalua si la sagnia (indentació), els espais i els comentaris compleixen amb l'estil formal del curs.
  • debug50 ./nom: Inicia el depurador gràfic pas a pas emprant punts d'interrupció (breakpoints) per comprovar quin valor prenen les variables en cada línia.
  • make nom: Compila el programa i mostra avisos d'error (warnings o errors) indicant el número de línia exacte.

🎯 Punts Clau per a l'Examen de la UP2

  • Tipus de dades: Tria sempre el tipus adequat (int per a enters, float/double per a decimals, char amb cometes simples 'a', string amb dobles "hola").
  • Entrades i Eixides: Associa cada get_...() amb el seu tipus de variable i cada variable amb el seu marcador en printf (%i, %f, %c, %s).
  • Funcions: Recorda posar sempre el prototip abans de main acabat en ;, especificar el tipus de cada paràmetre i utilitzar return quan la funció no siga void.
