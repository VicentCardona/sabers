PART I · FLUX DE TREBALL I PRIMERS PASSOS

1. L'Entorn cs50.dev i la Consola Linux

A diferència dels llenguatges visuals per blocs com Scratch, en C treballem directament amb la línia d'ordres (CLI). Per evitar discrepàncies de configuració entre sistemes operatius, utilitzem cs50.dev, un entorn basat en VS Code executat en un contenidor al núvol.

📁 Ordres Fonamentals de la Shell

  • ls: llista fitxers i carpetes del directori actual.
  • cd nom_carpeta: canvia el directori de treball cap endavant.
  • cd ..: retrocedeix un nivell en l'arbre de directoris.
  • mkdir nom: crea una nova carpeta (make directory).
  • rm nom_fitxer: esborra de manera permanent un fitxer.
  • cp i mv: copia i mou (o reanomena) fitxers.

☁️ Per què cs50.dev?

Garanteix que cada estudiant dispose del mateix conjunt de ferramentes preconfigurades: compilador clang, automatització amb make, la biblioteca docent cs50.h, i les eines de verificació check50 i style50.

2. Codi Font, Compilador i Codi Màquina

El maquinari només executa patrons binaris de 0s i 1s (codi màquina). El text que escrivim en arxius .c és codi font, comprensible per humans, que requereix un compilador per traduir-se:

Cicle de Compilació:
Codi Font (.c)  →  COMPILADOR (Clang / Make)  →  Binari Executable
# 1. Obrir l'arxiu i escriure el codi font
code hello.c

# 2. Compilar invocant make (sense l'extensió .c!)
make hello

# 3. Executar l'executable binari generat
./hello

3. El Primer Programa: "hello, world"

Anatomia bàsica d'un programa en C:

// Programa inicial tradicional en C
#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
}

Anatomia del Codi

  • #include <stdio.h>: fitxer de capçalera (header file) que declara funcions estàndard com printf.
  • int main(void): punt d'entrada del programa. La paraula clau void entre parèntesis indica que la funció no rep cap argument[cite: 19].
  • \n: salt de línia.
  • ;: tanca cada instrucció; sense ell el compilador llança un error sintàctic.

Seqüències d'Escapament Habituals

  • \n: Salt de línia.
  • \t: Tabulació horitzontal.
  • \": Cometes dobles literals dins d'un string.
  • \\: Barra invertida literal.

4. Tipus de Dades, Memòria i Variables

En llenguatges moderns com PHP o JavaScript les variables determinen el seu tipus dinàmicament[cite: 13]. En C, cal especificar de forma explícita el tipus de cada variable en crear-la per indicar al compilador quants bytes de memòria reservar[cite: 13, 14, 16, 17, 18, 24].

Tipus Mida Rang i Característiques Format printf Funció cs50.h
int 4 bytes (32 bits)[cite: 14] Sencers amb signe: de -231 a 231 - 1 (~ ±2.000 milions)[cite: 14] %i o %d get_int()
unsigned int 4 bytes (32 bits)[cite: 14, 15] Qualificador que duplica el rang positiu eliminant els negatius: de 0 a 232 - 1 (~ 0 a 4.000 milions)[cite: 15] %u —
char 1 byte (8 bits)[cite: 16] Caràcter únic entre cometes simples (-128 a 127). Mapeig ASCII: 'A'=65, 'a'=97, '0'=48[cite: 16] %c get_char()
float 4 bytes (32 bits)[cite: 17] Nombres reals en coma flotant (precisió limitada de 32 bits)[cite: 17] %f get_float()
double 8 bytes (64 bits)[cite: 18] Nombres reals amb doble precisió (per a càlculs científics o molts decimals)[cite: 18] %lf get_double()
bool 1 byte[cite: 16, 21] Valors lògics: true o false (requereix <cs50.h>)[cite: 21] %i —
string Variable Cadena de text entre cometes dobles (proporcionat per <cs50.h>)[cite: 22] %s get_string()
void — Tipus que indica absència de valor/retorn. No es pot assignar a una variable[cite: 19]. — —

Declaració vs Inicialització

Crear una variable requereix tipus i nom[cite: 24]. Si li assignem valor d'immediat, s'anomena inicialització[cite: 25]:

// 1. Declaració i assignació en línies separades
int number;         // Declaració[cite: 24, 25]
number = 17;        // Assignació[cite: 25]

// 2. Inicialització directa
int edat = 20;      // Inicialització[cite: 25]
char lletra = 'A';   // Mapeig ASCII 65[cite: 16, 25]

// Declaració múltiple del mateix tipus:
int ample, alt;     // Vàlid en C[cite: 24]

Bones Pràctiques i Advertències

  • No redeclarar: Un cop declarada una variable (ex: int x;), utilitza-la directament (x = 10;)[cite: 25]. Tornar a escriure int x = 10; pot produir comportaments imprevistos[cite: 25].
  • Declaració sota demanda: És millor declarar les variables just quan es necessiten i no necessàriament totes al principi del fitxer[cite: 24].
  • El tipus void: S'empra per a funcions que no retornen cap dada (com printf) o que no prenen paràmetres (int main(void))[cite: 19].

Exemple interactiu: hello.c amb la llibreria cs50.h

#include <cs50.h>
#include <stdio.h>

int main(void)
{
    // Demanem el nom a l'usuari i el guardem en una variable de tipus string
    string name = get_string("Com et dius? ");

    // Substituïm %s pel contingut de la variable name
    printf("Hola, %s!\n", name);
}

5. Operadors Aritmètics, Relacionals i Lògics

C disposa d'un conjunt d'operadors per transformar valors i avaluar condicions[cite: 2].

Aritmètica i l'Operador Mòdul (%)

A més de la suma (+), resta (-), multiplicació (*) i divisió (/), disposem del mòdul[cite: 3]:

  • %: Retorna el residu d'una divisió entera[cite: 3]. Ex: 13 % 4 dóna com a resultat 1 (ja que 13 = 4 × 3 + 1)[cite: 3].
  • Molt útil per acotar nombres en un rang (ex. en generadors de números aleatoris) o per determinar si un nombre és parell (n % 2 == 0).
// Operadors aritmètics abreujats
x += 5;   // Equivalent a: x = x + 5[cite: 4]
x *= 2;   // Equivalent a: x = x * 2[cite: 4]

// Increment i decrement unitari
x++;      // Incrementa x en 1 (x = x + 1)[cite: 4]
x--;      // Decrementa x en 1 (x = x - 1)[cite: 4]

Expressions Booleanes i Lògiques

En C, qualsevol valor diferent de zero s'interpreta com a vertader (true), mentre que zero és fals (false)[cite: 6].

  • ==: Igualtat[cite: 11]. Compte: = és assignació, mentre que == és comparació[cite: 11].
  • !=: Diferent de (desigualtat)[cite: 11].
  • <, >, <=, >=: Menor, major, menor o igual, major o igual[cite: 10].
  • && (AND): Cert només si tots dos operands són certs[cite: 7].
  • || (OR): Cert si com a mínim un operand és cert[cite: 8].
  • ! (NOT): Inverteix el valor lògic (de fals a cert i viceversa)[cite: 9].
PART III · CONTROL DE FLUX

6. Presa de Decisions (Condicionals)

Permeten que el programa seguisca rutes diferents segons si una condició avalua com a certa o falsa[cite: 5].

#include <cs50.h>
#include <stdio.h>

int main(void)
{
    char c = get_char("Hi estàs d'acord? (s/n): ");

    // Comprovem si l'usuari ha introduït 's' o 'S'
    if (c == 's' || c == 'S')
    {
        printf("D'acord.\n");
    }
    else if (c == 'n' || c == 'N')
    {
        printf("No d'acord.\n");
    }
    else
    {
        printf("Opció invàlida.\n");
    }
}

7. Repetició de Tasques (Bucles)

Estructures iteratives per executar instruccions de manera repetida mentre es complisca una condició[cite: 5]:

Bucle while

Executa el bloc mentre la condició siga certa. La condició es comprova abans d'entrar:

int i = 0;
while (i < 3)
{
    printf("meow\n");
    i++;
}

Bucle for

Estructura idònia quan sabem per endavant el nombre de repeticions:

for (int i = 0; i < 3; i++)
{
    printf("meow\n");
}

Bucle do-while: Validació d'Entrades

Executa el codi intern almenys una vegada i avalua la condició al final. És el patró estàndard a CS50 per filtrar entrades d'usuari i rebutjar dades no vàlides:

#include <cs50.h>
#include <stdio.h>

int main(void)
{
    int n;
    // Forcem la repetició mentre l'usuari introduïsca un valor menor a 1
    do
    {
        n = get_int("Introdueix un nombre positiu: ");
    }
    while (n < 1);

    for (int i = 0; i < n; i++)
    {
        printf("meow\n");
    }
}

8. Bones Pràctiques, Disseny i Eines de Suport CS50

A CS50 no només s'avalua el funcionament (Correctness), sinó el disseny i la claredat (Style):

🛠️ Eines Pedagògiques

  • style50 nom.c: Avalua si la sagnia, espais i comentaris compleixen amb l'estil formal.
  • check50 cs50/problems/2026/x/hello: Executa bateries de proves automàtiques per comprovar la correcció abans de l'entrega.
  • debug50 ./nom: Inicia el depurador gràfic amb punts d'interrupció (breakpoints) per analitzar el canvi d'estat pas a pas.

💡 Consells per a l'Alumnat

  • Indexació en zero: En informàtica els comptadors comencen habitualment a 0, no a 1.
  • Evita números màgics: Empra variables descriptives o constants amb const per aclarir el significat dels límits.
  • Abstracció: Si un fragment de codi es repeteix més de dues vegades, encapsula'l dins d'un bucle o funció.
