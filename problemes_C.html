Activitats Pràctiques UP2: Tipus de Dades, E/S i Funcions en C

Enunciats detallats de les dues pràctiques avaluables de la Unitat de Programació 2. Resol els reptes en cs50.dev aplicant l'estructura modular amb funcions i lliura els fitxers .c a Google Classroom.

📥 Instruccions Generals i Com Entregar des del Chromebook

Totes les activitats s'han de programar i provar dins del teu espai de treball a cs50.dev. És imprescindible que els fitxers s'anomenen exactament com s'indica a cada enunciat perquè el sistema de correcció automàtica els reconega.

1. Creació i Compilació a cs50.dev

  1. Obre la terminal de cs50.dev i escriu code nom_fitxer.c per crear l'arxiu.
  2. Escriu el teu codi incloent les llibreries <cs50.h> i <stdio.h>.
  3. Compila sempre amb make nom_fitxer (sense el .c) i comprova que no hi ha cap error.
  4. Prova el programa executant ./nom_fitxer amb diferents valors.

2. Descàrrega i Entrega a Classroom

  1. A la barra lateral esquerra de cs50.dev (Explorer), busca el teu fitxer .c (no l'executable sense extensió!).
  2. Fes clic dret sobre el fitxer .c → Download per descarregar-lo al teu Chromebook.
  3. Entra a la tasca corresponent de Google Classroom, adjunta el fitxer .c i prem Entregar.

Objectiu de l'activitat: Practicar els tipus string i float, la lectura amb get_string() i get_float(), el format de decimals %.2f i la creació dels 3 tipus de funcions vistes a classe.

void mostrar_capcalera(void); Sense entrades ni retorn Imprimeix per pantalla un títol o bàner decoratiu per al butlletí de notes.
float calcular_mitjana(float n1, float n2); Amb entrades i retorn (return) Rep les dues notes amb decimals, calcula la mitjana aritmètica (n1 + n2) / 2.0 i retorna el resultat.

REPTE 2 · NIVELL AVANÇAT (INTEGRADOR)

🟠 Activitat 2: Caixa Registradora i Descomptes (botiga.c)

En aquesta segona activitat programaràs un simulador de facturació anomenat botiga.c per a una botiga d'informàtica. El programa demanarà el nom del producte, el preu unitari, el nombre d'unitats i el tipus de client per aplicar descomptes automàtics, afegir l'IVA (21%) i imprimir el tiquet de compra.

Objectiu de l'activitat: Combinar tots els tipus de dades (string, float, int, char), operadors lògics (||, &&), condicionals encadenats (if / else if / else) i disseny modular amb múltiples funcions que es comuniquen entre si.

Regles de Negoci i Tarifes de la Botiga

  • Tipus de client (char): L'usuari introduirà una lletra que pot ser majúscula o minúscula:
    • 'E' o 'e' (Estudiant): S'aplica un 15% de descompte sobre el subtotal (multiplica per 0.85).
    • 'V' o 'v' (Client VIP): S'aplica un 25% de descompte sobre el subtotal (multiplica per 0.75).
    • 'N' o 'n' (Client Normal) o qualsevol altra lletra: 0% de descompte (preu íntegre).
  • Càlcul d'IVA: Sobre el preu ja rebaixat s'afegeix un 21% d'IVA (multiplica per 1.21).
  • Enviament Gratuït: Si el total final amb IVA és igual o superior a 50.00 €, el tiquet ha d'indicar Enviament: GRATUIT. Si és inferior a 50.00 €, ha d'indicar Enviament: 4.99 EUR.

Funcions Obligatòries a Implementar

Prototip de la Funció Descripció
void mostrar_tarifes(void); Mostra per pantalla la capçalera de la botiga i el resum de codis de client (E = -15%, V = -25%, N = 0%).
float calcular_subtotal(float preu, int unitats); Rep el preu d'una unitat i la quantitat comprada, i retorna el subtotal sense descompte (preu * unitats).
float aplicar_descompte(float subtotal, char tipus); Avalua la lletra tipus amb if / else if / else i l'operador || (per acceptar majúscules i minúscules) i retorna l'import amb el descompte aplicat.
float afegir_iva(float base); Rep l'import amb descompte i retorna el preu final multiplicat per 1.21.
void imprimir_tiquet(string prod, int unitats, float subtotal, float total_final); Imprimeix el tiquet de compra ben formatat (amb 2 decimals %.2f) i comprova si té dret a Enviament: GRATUIT (>= 50.0) o Enviament: 4.99 EUR.
